Windows 10/11 x64 与 macOS 13+ Apple Silicon 的 Codex 启动动画控制中心。

1. 下载 Windows `control-center.zip` 或 `setup.exe`；Mac 下载 `macos-arm64.dmg` 或 ZIP。
2. 解压到固定目录（Windows），或将 App 放入“应用程序”（Mac）。
3. 打开 **Codex Boot Animation**，选择随附 Dragon 主题，先预览，再点击“启用启动动画”。启用前自动备份。
4. 退出后重新启动 Codex 测试。Windows 仅覆盖可识别的快捷方式；Mac 已运行的 Codex 被再次激活时不会重播。
5. 移动或删除应用前，先在控制中心点击“停用启动动画”。

默认主题和视频已随桌面包附带，无需单独下载 MP4。`demo-theme.zip` 可解压后通过“导入本地主题”使用。网页中编辑的主题不会自动同步到桌面端。

macOS 包使用 ad hoc 签名，暂未 Apple 公证；首次打开请使用系统提供的允许打开流程。Windows 包尚未配置代码签名。项目是社区工具，与 OpenAI 无隶属关系，不修改官方 Codex 应用。代码 MIT，演示素材使用单独的媒体许可。

---

Desktop control center for Windows 10/11 x64 and macOS 13+ Apple Silicon.

Download the Windows control-center ZIP / setup EXE, or the macOS arm64 DMG / ZIP. Extract Windows packages to a permanent folder; move the Mac app to Applications. The Dragon demo is included: preview first, then explicitly enable integration. A backup is created before enabling. Disable integration before moving or deleting the app.

The optional demo-theme ZIP can be extracted and imported as a local theme. Browser edits do not sync to the desktop. Windows integration covers recognized shortcuts; macOS does not replay when an already-running Codex is activated.

macOS packages use ad hoc signing and are not notarized; Windows packages do not yet have code signing. Independent community project, not affiliated with OpenAI. Code is MIT; demo media has a separate license notice. SHA-256 files are supplied for every download.
